# bot_allert

[English](README.md) · **Українська**

Telegram-бот, якого ви запускаєте у себе. Він збирає нові пости з каналів однієї вашої папки Telegram і надсилає їх вам в один чат. Пости з каналів, які у вас вимкнені (без звуку), приходять беззвучно. Пости з решти каналів приходять зі звуком.

Бот створений для каналів з повітряними тривогами: ви стежите за десятком каналів, складаєте їх в одну папку й отримуєте одну стрічку, де важливі канали дзвонять, а решта ні.

Кожен запускає власну копію для свого акаунта. Нічого спільного немає, центрального сервера теж.

## Як це працює

Один процес запускає два клієнти Telegram:

- **юзербот**, увійшовший у ваш акаунт. Він лише читає: ваші папки, налаштування сповіщень для кожного каналу та нові пости в цих каналах. Він нічого не публікує, не позначає прочитаним, нікуди не вступає і нічого не покидає;
- звичайний **бот**, який надсилає пости вам.

На кожен новий пост юзербот перевіряє, чи вимкнені зараз сповіщення цього каналу у вашому Telegram. Потім бот пересилає пост (текст із форматуванням, фото, файли) зі звуком або без нього. Зміна налаштувань каналу діє вже з наступного поста, перезапуск не потрібен.

## Що потрібно

- акаунт Telegram;
- комп'ютер, який завжди увімкнений: VPS, домашній сервер або ноутбук для перевірки. Для бота достатньо [безкоштовної віртуалки Oracle Cloud](#безкоштовний-хостинг-на-oracle-cloud), описаної нижче;
- [Docker](https://docs.docker.com/get-docker/) або Python 3.12+ з [uv](https://docs.astral.sh/uv/).

## Налаштування

### 1. Отримайте ключі

1. **API_ID і API_HASH.** Увійдіть на <https://my.telegram.org> зі свого акаунта, відкрийте **API development tools** і створіть застосунок. Назва та платформа можуть бути будь-якими.
2. **BOT_TOKEN.** У Telegram відкрийте [@BotFather](https://t.me/BotFather), надішліть `/newbot` і виконайте кроки.

### 2. Налаштуйте

```bash
git clone https://github.com/VladSkopenko/bot_allert.git
cd bot_allert
cp .env.example .env
```

Відкрийте `.env` і заповніть `API_ID`, `API_HASH` та `BOT_TOKEN`.

### 3. Увійдіть у свій акаунт (один раз)

```bash
docker compose run --rm bot python -m bot_allert.login
# або без Docker:
uv run --env-file .env python -m bot_allert.login
```

Скрипт попросить номер телефону, код від Telegram і пароль двоетапної перевірки, якщо він є. Потім він виведе довгий рядок. Вставте його в `.env` як `USER_SESSION`.

> [!WARNING]
> `USER_SESSION` дає повний доступ до вашого акаунта Telegram. Нікому його не передавайте і не публікуйте `.env` (він уже в `.gitignore`). Якщо рядок витік, завершіть сеанс у Telegram → Налаштування → Пристрої.

### 4. Відкрийте чат із ботом

Зі свого акаунта відкрийте нового бота й натисніть **Start**. Бот не може писати людині, яка жодного разу його не запускала.

### 5. Запустіть

```bash
docker compose up -d --build
docker compose logs -f bot
```

Без Docker:

```bash
uv run --env-file .env python -m bot_allert
```

## Використання

1. У Telegram створіть папку (Налаштування → Папки з чатами) і **вручну** додайте до неї канали.
2. Надішліть боту `/folder <назва папки>`, наприклад `/folder Тривоги`.
3. Вимкніть у Telegram сповіщення каналів, пости з яких хочете отримувати беззвучно.

| Команда | Що робить |
|---|---|
| `/folder <назва>` | Обрати папку, за якою стежити. Вибір зберігається й переживає перезапуски. |
| `/status` | Показати поточну папку та кількість каналів у ній. |
| `/start` | Показати довідку. |

Бот відповідає лише вам (акаунту з `USER_SESSION`) і ігнорує всіх інших. Він відповідає російською.

Зверніть увагу:

- Враховуються лише канали, **додані до папки вручну**. Папки на основі правил, наприклад «усі канали», не підтримуються. Групи та особисті чати в папці пропускаються.
- Зміни в папці бот підхоплює кожні `FOLDER_REFRESH_SECONDS` (за замовчуванням 10 хвилин) або одразу, якщо знову надіслати `/folder`.
- Не вимикайте сповіщення самого чату з ботом, інакше всі пости приходитимуть беззвучно.

## Безкоштовний хостинг на Oracle Cloud

Боту потрібно дуже мало (близько 100 МБ пам'яті) і не потрібні відкриті порти, тож він безкоштовно працює на тарифі Always Free від Oracle Cloud.

1. **Створіть віртуалку.** У консолі Oracle Cloud відкрийте **Compute → Instances → Create instance**.
   - Image: **Canonical Ubuntu 24.04**.
   - Shape: **VM.Standard.E2.1.Micro** (у розділі *Specialty and previous generation*) або **VM.Standard.A1.Flex**. Обидва позначені *Always Free-eligible*. A1 часто видає «Out of capacity». Тоді беріть E2.1.Micro в тій зоні доступності, яку вказує Oracle.
   - Networking: **Create new virtual cloud network** і **Create new public subnet**.
   - SSH keys: завантажте свій публічний ключ, наприклад створений командою `ssh-keygen -t ed25519 -f ~/.ssh/oracle_bot`.
2. **Додайте публічну IP-адресу**, якщо її немає: інстанс → **Networking** → VNIC → **IP administration** → ⋮ → **Edit** → **Ephemeral public IP**.
3. **Встановіть Docker** і додайте swap, щоб образ зібрався на 1 ГБ пам'яті:
   ```bash
   ssh -i ~/.ssh/oracle_bot ubuntu@<IP>
   curl -fsSL https://get.docker.com | sudo sh
   sudo usermod -aG docker ubuntu
   sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
   echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
   exit
   ```
4. **Скопіюйте проєкт і запустіть.** Виконайте на своєму комп'ютері, в папці проєкту із заповненим `.env`:
   ```bash
   rsync -az -e "ssh -i ~/.ssh/oracle_bot" --exclude .venv --exclude data ./ ubuntu@<IP>:~/bot_allert/
   ssh -i ~/.ssh/oracle_bot ubuntu@<IP> 'cd bot_allert && chmod 600 .env && docker compose up -d --build'
   ```

Щоб оновити бота пізніше, повторіть крок 4. Папка `data/` не копіюється, тож обрана на сервері папка збережеться.

> [!IMPORTANT]
> Запускайте лише одну копію бота. Дві копії з тією самою сесією й токеном бота надсилатимуть кожен пост двічі.

## Обмеження

- Пости, опубліковані, поки бот не працював (наприклад, під час перезапуску), потім не надсилаються.
- Альбоми приходять окремими повідомленнями.
- Редагування та видалення постів не відстежуються.

Детальніше в [docs/known-limitations.md](docs/known-limitations.md) (англійською). Початкова специфікація в [docs/spec.md](docs/spec.md).
